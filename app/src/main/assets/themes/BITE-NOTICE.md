# 8bitBites theme adaptation

The bundled catalogue and original license notices are preserved from 8bitPad.
8bitBites uses the background, foreground and accent roles to derive Material 3
color schemes. It does not include 8bitPad's Qt/Scintilla theme implementation.
The new Compose adaptation is GPL-3.0-or-later, like 8bitBites.
Upstream palette attribution is in NOTICES.md and licenses/.
